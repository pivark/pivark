元舟 PivArk Community — 安装说明
================================

本包为「建站安装包」（已含 PHP 依赖与后台界面，解压即可安装）。
版本：1.6.5（校验和见官网下载页）

官网快捷方式：双击根目录「打开官网.url」可打开 https://pivark.cn/

--------------------------------
环境要求
--------------------------------

  PHP     8.1 及以上（扩展：pdo_mysql、json、mbstring、openssl、curl；建议 gd、zip、fileinfo）
  MySQL   8.0 及以上
  Web     Nginx / Apache / IIS；站点根目录指向「本包根目录」（与 index.php 同级）
  权限    data/、data/runtime/、public/uploads/ 需 Web 用户可写

--------------------------------
安装步骤
--------------------------------

  1. 将本 zip 解压到网站目录（勿多一层空文件夹）。
  2. 在面板中创建 MySQL 数据库，记下库名、用户名、密码。
  3. 绑定域名，确认 PHP 版本 >= 8.1。
  4. 浏览器访问：http://你的域名/
     未安装时会自动进入安装向导（/install/index）。
  5. 按向导填写数据库信息与管理员账号，提交后等待完成。
  6. 安装成功后进入后台登录；请立即修改管理员密码。

安装过程会自动生成根目录 .env（数据库等配置），无需手工编辑 config/。

--------------------------------
安装后入口
--------------------------------

  网站首页    /
  后台管理    /admin

升级、备份、插件说明见官网文档（本包不含 docs/ 知识库）。

--------------------------------
开发者 / 二次开发
--------------------------------

本安装包不含源码构建链（无 admin/ Vue 源码、无完整 devtools/、无 composer.json）。

如需完整开源仓库（clone、改代码、跑测试、构建后台）：

  Gitee   https://gitee.com/pivark/pivark（以官网公布为准）
  GitHub  https://github.com/pivark/pivark（以官网公布为准）
  产品站  https://pivark.cn

请从上述地址获取完整仓，勿将本安装包当作开发仓库。
