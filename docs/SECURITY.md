# 部署安全提示（Community）

上线前请逐项核对。安全无捷径。

## 安装向导

- [ ] 安装成功后**删除或禁止访问** `/install`（删目录，或 Nginx/Apache 直接 `deny`）  
- [ ] 确认存在 `data/install.lock`，避免公网重复进入向导  
- [ ] 向导中自设的管理员密码足够强，装完立刻再改一次  

## 调试与报错

- [ ] 生产环境**关闭调试模式**（不要把 PHP/框架异常栈展示给访客）  
- [ ] 日志写到不可 Web 直读的目录；勿把 `.env` / `site.env` 放到可下载路径  

## 传输与权限

- [ ] 全站 HTTPS（尤其 `/admin` 登录）  
- [ ] 代码目录仅部署用户可写；Web 用户对 `data/`、`public/uploads/` 可写即可  
- [ ] 数据库账号最小权限（勿用 root 跑站点）  

## 备份与升级

- [ ] 定期自动备份数据库与上传  
- [ ] 升级前必备份；按 [UPGRADE.md](UPGRADE.md) 操作  
- [ ] 不要在未备份时对生产库执行手工 DROP  

## 插件与上传

- [ ] 只安装可信来源插件  
- [ ] 限制上传类型与大小；后台按需开启扫描等安全能力  

## 出事时

1. 切维护页 / 断公网写入  
2. 保留日志与现场  
3. 从备份恢复，再补漏洞与密码轮换
