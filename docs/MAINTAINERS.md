## 维护承诺（Community）

- **发行节奏**：以 `1.6.x` 为主线持续加固；新能力优先合入 `dev`，稳定后打标签发版。  
- **问题反馈**：Gitee / GitHub Issues（请附 PHP/MySQL 版本、复现步骤）。  
- **安全漏洞**：[SECURITY.md](SECURITY.md) 私下通报，勿公开利用细节。  
- **贡献**：[CONTRIBUTING.md](../CONTRIBUTING.md) — PR 默认打向 **`dev`**。
